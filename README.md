# Mapprentice

Was getting cooked on [Maptap Versus](https://maptap.gg/versus), so I wanted to create a geography study app to allow for better personalized study. Much like Maptap, this will function by presenting a location and asking the user to identify it on an interactive glove. Guesses will **eventually** be evaluated by geographic distance, saved for review, and used to prioritize places that the user is worse at identifying in the future.
